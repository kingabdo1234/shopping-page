# NOVA MARKET — Professional E-Commerce Storefront

NOVA MARKET is a realistic, responsive, client-side e-commerce storefront created with **Vanilla HTML5, CSS3, and JavaScript (ES6+)**. Designed to showcase professional front-end design, modular architecture, state management with `localStorage`, and interactive design patterns suitable for a freelance web development portfolio (e.g., Mostaql, Upwork).

---

## 🌟 Key Features

- **Responsive Mobile Navigation**: Clean desktop navigation bar that converts into an accessible mobile menu drawer.
- **Product Catalog Search & Filtering**: Instant dynamic search by product titles and descriptions, filtering by category, and sorting by price, rating, or name.
- **Interactive Quick View**: Accessible modal dialog enabling product previews and quantity selections without leaving the store page.
- **Persistent Shopping Cart**: Slide-out cart drawer supporting item count updates, item removal, dynamic subtotal calculation, and persistence using browser `localStorage`.
- **Free Shipping Progress Tracker**: Dynamic visual progress indicator motivating users to add items up to the $75 free shipping threshold.
- **Wishlist Manager**: Toggle items to saved wishlist with persisted local storage state.
- **Simulated Checkout Workflow**: Client-side validation for address and customer inputs with order confirmation dialogs.
- **Clean Accessibility & Security**: Safe DOM rendering (HTML escaping against cross-site scripting), clear focus indicators, keyboard support (`Escape` modal dismissal), and ARIA labels.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic document layout (`header`, `main`, `section`, `article`, `footer`, `aside`).
- **CSS3**: CSS Custom Properties (Variables), Flexbox, CSS Grid, custom scrollbars, and mobile-first media queries.
- **Vanilla JavaScript (ES6+)**: Custom dynamic state management, event delegation, and `localStorage` API. No external JS libraries or frameworks.
